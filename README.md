# 星脈のワイルズ（仮）

ブラウザで遊べる 2D 見下ろし型オープンワールド・アクションアドベンチャー（iPhone 対応）。
設計書：[docs/DESIGN.md](docs/DESIGN.md)

現在の段階：**P8（オープンワールド基盤）**。島の南に「風の草原」と「赤砂の荒野」が加わり、浜から砂の道で歩いて行けます。地形はチャンク単位で読み込み・解放し、地方ごとの絵も近づくと読み込みます。変えた物は差分でセーブされます。これまで：P7（謎解きと能力）星環の 4 能力（灯火・念動・蔓結び・共鳴）と、光る石柱から入る 3 つの試練が加わりました。どの試練も 2 通り以上で解けます。これまでの内容：P6（アイテムと装備）武器・弓・防具（耐久度と強化）、拾う・食べる・料理する、お金（星貨）が加わりました。これまでの内容：最初の島に時間の流れ（1 日 24 分）と天候（晴れ・くもり・雨・雷雨）があります。夜は暗くなり、火が明かりになります。雨は火を消し、崖を滑りやすくし、雷雨では雷が落ちます。風は延焼と滑空に影響し、火の上では上昇気流に乗れます。

## 遊ぶ・確認する

- 公開版：https://clubzfirst2-byte.github.io/my-jrpg-game/
- アプリのように使う（P11.1）：iPhone の Safari で開き、「共有 → ホーム画面に追加」。一度開けば、電波がなくても遊べる
- 計測表示を最初から開く：`?debug=1`
- 負荷テストのスプライト数を指定：`?bench=1000`
- 計測レポートの時間（秒）を変更：`?reportSec=60`
- 内部解像度の候補を指定：`?res=180` / `?res=216` / `?res=270`（計測パネルの「解像度」ボタンでも切り替え可。選んだ値は保存される）
- マップを選ぶ：`?map=world`（世界全体）/ `?map=island`（最初の島だけ）/ `?map=height`（高さ検証マップ）/ `?map=field`（P1 の平らなフィールド）。`?map=` を付けるとタイトル画面を飛ばし、**保存もしない**（確認・テスト用）
- カメラのズーム倍率：`?zoom=2`（1〜4。確認用）
- 長時間プレイ測定：計測パネルの「自動巡回 60分」、または `?map=world&tour=60&debug=1`（終わるとレポートが出る）
- 時刻・天候・季節を指定：`?time=22`（時）/ `?weather=rain`（`clear` / `cloudy` / `rain` / `storm` / `snow`）/ `?season=winter`（`spring` / `summer` / `autumn` / `winter`）/ `?light=0`（ライトを消す）
- フレームレートを制限：`?fps=30`（30fps でもゲームの速さが変わらないことの確認用）

## 操作

| 操作 | タッチ | キーボード |
|---|---|---|
| 移動 | 画面の左半分をドラッグ（触った場所にスティックが出る） | 矢印キー / WASD |
| ジャンプ | 右下の「ジャンプ」 | Space（または K） |
| 滑空 | 空中でもう一度「ジャンプ」（もう一度押すと閉じる） | 同じ |
| 泳ぐ | 水に歩いて入る（「ダッシュ」で速く泳ぐ。スタミナが切れると岸に戻される） | 同じ |
| 崖を登る | 崖に向かって押し続ける（登攀中：壁の方向＝登る、反対＝下りる、横＝横移動、ジャンプ＝手を離す） | 同じ |
| ダッシュ | 「ダッシュ」を押しながら移動 | Shift |
| 攻撃（剣・3 段コンボ） | 「攻撃」 | J |
| 宝箱を開ける | 宝箱の前で、宝箱の方を向いて「攻撃」 | J |
| 住人に話しかける | 住人の前で、住人の方を向いて「攻撃」（または画面下の「話す」）。文字送りは画面をタップ | J / Enter / Space |
| 家に入る・出る | 扉の前で上に歩く（出るときは玄関マットの上で下に歩く） | 同じ |
| 眠る（朝・夕方まで） | 宿などのベッドの前で「攻撃」（または画面下の「眠る」） | J |
| 火矢 | かがり火・たき火・燃えている所の上を通るように矢を撃つ | U |
| 雷の結晶・水がめ・いばら | 剣で叩く（結晶と水がめは矢でもよい。いばらは 3 回切る） | J |
| 持ち物（装備・食べる・クエスト） | 左上の「持ち物」 | E / Tab |
| 料理・鍛冶 | たき火・かまどや金床の近くで、画面下の「料理する」「鍛冶」 | E |
| 拾う | 落ちている物の上を歩く | 同じ |
| 星環の能力を使う | 右の「能力」（灯火・念動・蔓結び・共鳴） | Q |
| 能力を切り替える | 「能力」の横の ⇄（持ち物の「能力」でも選べる） | R |
| 回避（攻撃の直前でジャスト回避） | 「回避」 | L |
| ガード（攻撃の直前でジャストガード） | 「ガード」を押している間 | I（押している間） |
| 弓 | 「弓」を押して狙い、離して撃つ | U（押している間） |
| 一時停止 | 左上の「Ⅱ」 | — |

**保存**：宝箱を開けたとき・記録石に触れたとき・1 分ごと・アプリを切り替えたときに自動で保存します。次に開いたときにタイトル画面の「つづきから」で再開できます。

画面右上の「計測」で、FPS・フレーム時間・描画回数・テクスチャ数などを表示します。
エラーが起きると、赤い「エラー n」ボタンが出ます。押すと内容を確認できます。

## 開発

```bash
npm install
npm run dev        # 開発サーバ（同じ Wi-Fi の iPhone から表示された URL で開ける）
npm run lint       # ESLint（src/game が描画層に依存していないかも検査）
npm run typecheck  # JSDoc の型チェック
npm test           # 単体テスト（Vitest）
npm run test:e2e   # ビルド＋E2E（Playwright、iPhone サイズ）
npm run check      # 上記すべて
```
