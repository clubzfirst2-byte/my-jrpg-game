## 1. 物語（1 ページ）

**題名の意味**：レガリアは「王のしるし」。この物語では、星環の姫の**額飾り**と、主人公の**ペンダント**の 2 つ。もとは 1 つの「星環の要石（かなめいし）」を 2 つに分けたものです。

**むかし（百年前）**
大陸アウラの地下には、力の川「星脈」が流れている。大陸の真ん中には、星脈を束ねる大きな「星環」があり、古代の「灯（ともしび）の民」の姫がそれを守っていた。
ある時、星脈が淀み、真ん中に黒い渦「淀みの源」が生まれた。姫は自分の体ごと星環の中に入り、源を押さえ込んだ。そして要石を 2 つに割り、片方（額飾り）を自分に、もう片方（ペンダント）を 1 人の守り手に預けた。守り手は浜の小さな星環で眠りにつく。「封印が弱まったら、目を覚まして」と。眠りの代わりに、守り手は記憶を置いてきた。

**いま**
百年たち、封印は弱まった。淀みは 4 つの地方に根を張り、「澱の核」になって土地を蝕んでいる。

**はじまり（言葉のない場面）**
浜の星環が光り、少年が目を覚ます。起き上がり、胸のペンダントが青く光るのを見つめる。顔を上げると、島の北に灯台塔が見える。——台詞は一つもない。

**星環の姫**
灯台塔の頂上の祭壇（共鳴の力を授かる場所）で、ペンダントが鳴り、姫の「写し身」（半透明の姿）が現れる。体は大陸の真ん中にあり、祭壇を通して話している。姫は主人公を知っているが、主人公は姫を覚えていない。姫は**頼む側でありながら、記憶を奪ったことを謝る**人物。凛としていて、口元はやわらかい。武器を持たず、命令もしない（「力を貸してくれますか？」）。

**4 つの核**
森「朽ち根のヌシ」・山「凍て角のヌシ」・荒野「砂嵐のヌシ」・湖「雷鳴のヌシ」。どの順でもよい。1 つ浄化するたびに、姫・見張り・村の子・村の女性の台詞が変わる。村の人の頼みごと（各地方に 1 つ）が、自然に各地方へ足を向けさせる。

**淀みの源**
4 つを浄化して祭壇へ戻ると、ペンダントと額飾りが同じ音で鳴り、目覚めた浜の星環が「大陸の真ん中への門」になる。輪に入ると、淀みの源の闘技場。源は 4 体の核の技をすべて使う（突進・叩きつけ・扇の弾・全方位の弾）。

**終わり**
源が消え、星環の中から姫が自分の体で現れる。姫は「ペンダントにしまってある、眠る前の記憶を返せる」と言う。主人公は**うなずく／首を横にふる**（言葉ではなく身ぶりで選ぶ）。どちらでも物語は同じ所に着く。姫が「わたしも、いっしょに行っていいですか？」と聞き、主人公はうなずくか手をさしだす。短いエンディング（スタッフ表示）のあと、風見の村の朝へ。

**クリア後**
世界はそのまま続く。姫は村にいて、記憶を選んだかどうかで台詞が少し違う。村の人たちの台詞も「霧が晴れたあと」に変わる。残っている試練・宝箱・クエストはそのまま遊べる。タイトル画面に「クリア済み」の印。

**オリジナルであること**：冠・ドレス・さらわれる姫・「伝説の勇者」といった定番は使わない。姫は自分の意思で封印を選んだ人で、主人公は「選ばれた勇者」ではなく、記憶と引きかえに約束を預かった守り手。名前・用語はすべてこの作品の世界観（星脈・澱・灯の民・星環）から作った。

## 4. 会話の下書き（データ形式）

- 下の JSON は `data/` に入れる前の**下書き**です（`data/` は変更していません）。
- `dialogues` の `elder` / `cook` / `guard` / `merchant` / `child` は、**既存の場面を一字も変えず**に、始まりの候補と新しい場面を足した完成形です。
- `npcs` は置き場所のメモ（`if`＝出ている条件、`ghost`＝半透明）。`if` と `ghost` は 5 章のコード追加が前提で、実際の座標は実装の時に地図で決めます。
- **確認済み**：今の `validateTalk`（`npm run check:data` と同じ検査）に、5 章 C2 の 2 行（条件 `cores`・`boss`、目標 `cores`）だけを足した写しで、この下書きを既存データと合わせて検査し、**エラー 0**（会話 11・クエスト 8・全場面にたどり着ける・全クエストに始める会話と報告する会話がある）。既存の場面が変わっていないことも機械的に確かめた。
- 主人公の台詞は 1 行もありません。選択肢は、新しい人物では身ぶり（「うなずく」「首を横にふる」「ペンダントを見つめる」「手をさしだす」）。既存 3 人の選択肢（「引き受ける」など）はそのまま。
- 「（カン、カン、と槌の音が響く）」は語り（主人公の台詞ではない）。

## 6. 決めてほしいこと

1. **源にいつ挑めるか**
   - A（おすすめ）：4 つの核を浄化して姫に報告した後だけ、門が開く。作るのも調整も簡単
   - B：最初から挑める（DESIGN.md 5.1 の「最初から源に挑むことも可能」のとおり）。浄化していない核の数だけ源が強くなる。調整の手間が増える
   - A にする場合、DESIGN.md 5.1 の文を直す
2. **姫に名前を付けるか**：「星環の姫」のままにする（おすすめ。物語の中で名前を呼ぶ場面がない）か、固有の名前を付けるか
3. **記憶を返すかの選択**（エンディングの 2 択）を入れるか。結末は同じで、クリア後の姫の台詞が 1 つ変わるだけ
4. **選択肢の言葉**：新しい人物は身ぶり（「うなずく」など）にした。既存の 3 人（「引き受ける」「見てくる」など）もそろえるか、そのままにするか（おすすめ：そのまま）
5. **星鋼の剣**（新しい品物 1 つ）を足してよいか。だめなら鍛冶職人の報酬は「旅人の剣＋星貨」にする
6. **主人公の身ぶりの絵**（うなずく・首をふる・ペンダントを見る）を v1.0 に入れるか（C12）
7. **エンディングの後**：村の朝に戻って遊び続けられる（おすすめ）か、タイトルに戻るか
8. **村に金床を置くか**（C13）
9. **v1.0 で住人の絵をどこまでそろえるか**：9 人全員を製品版の絵にしてから出すか、仮の絵が混じってもよいか（NPC の PR #45〜#47 と第 3 回の承認しだい）
10. **時代の数字**：「百年前」でよいか（長老・姫の台詞に出る）
