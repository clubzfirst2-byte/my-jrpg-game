## 2. 夜の窓（効果 v2 の決まり）

- `gfx/fx-v2` の `src/view/houseWindows.js` と同じ判定（`glassKind`：青が赤より 20 以上・青 ≥ 緑・明るさ 110 未満）で、**ガラスの画素だけ**が光る。映り込み（4・5 段）、窓枠、桟、花箱は光らない
- 窓の位置（ゲーム px、足もとから）と画素の数：`docs/art-release-v3/village_windows.json`（`game: [x, y, w, h]`）。ゲームの `HOUSE_WINDOWS` に当たる表。v3 の家を組み込むときは、この表と大きさ（192×224／256×288）で窓を引く
- ガラスの基本の色（3 段）を見本の `#4e7898` から `#4a7494` にした。見本の色は `glassKind` の明るさで 111 になり、窓の上半分が夜に光らなかったため（今は 107）。よろい戸の青緑も、緑を青より少し強くした（ガラスと間違えないため）
- **見本の夏の石の家（`obj.v3.house_stone.png`、1 人目の担当のファイル）は変えていない**。この 1 段だけ古い色のままなので、夜は窓の上半分が暗い（測定：光る 3321 点、光らないガラス 3008 点。秋・冬の版は光る 5878／5804 点、光らない映り込み 451 点）。直すなら、見本の作り方のガラスの 3 段を同じ値にする（担当に任せる）
