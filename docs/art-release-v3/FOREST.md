- **草原との境**：v2 の優先度で森の苔（moss）は草原（plains）より下なので、境のマスは「森の土台の上に草原の v3 のつなぎ目 `plains.grass.v3.edge.<mask>.<v>`」で描く（新しい絵は要らない。比較画像で確かめた）
- **決定：冬だけ、森と草原の組の優先度を入れ替える**（統括の決定 2026-11-12。ゲーム側が読む決まりは NAMES.md 2.1 節）
  - 冬に、4 つの角に森と草原の両方があるマスでは、優先度の並びの中で森と草原の位置を入れ替える（草原＜森）。道・砂・雪・遺跡は両方より下、`tile.grass` は両方より上のまま。森か草原のどちらかしかないマスは v2 の並びのまま
  - 描き方：草原の冬の土台（と流れの層）の上に、森の冬のつなぎ目 `winter.forest.grass.v3.edge.<mask>.<v>`（**mask＝森の角**）
  - **v の決め方**：v2 の NAMES.md 2 章の 3 のまま。ただし、mask はすべて「そのマス自身の冬の並び」で読む。mask 6・9 は `hash(i + 7, j) % 2`。ほかは横切る辺の状態 `s = (辺の hash >> 4) & 1` で、辺の端のセルが水の時と、**このマスか辺の向こうのマスの森の mask（向こうのマス自身の冬の並びで読む）が 6・9 の時は s = 0**
  - **斜めだけで接する所**（森のセルが (x, y) と (x+1, y+1) にあり、残りの 2 角が草原）：そのマスの森の mask は 9（または 6）なので、まわり 4 マスのその向きの辺は状態 0 になり、境がつながる。向こうのマスの mask を v2 の並び（森＜草原）で読むと 15 になって 0 にならず、v が違う（検査の地図の境のマス 140 のうち 3）。参照の実装：`compare_forest_v3.winter_forest_v`（検査の描画と 140／140 一致）
  - 理由：草原の冬のつなぎ目の 1 点幅の明るい縁が、雪と雪の境に白い鉛筆の線として出るため（検査 1 回目の P2-4）。森の冬のつなぎ目は縁の線なし。夏・秋はこれまでどおり（草原のつなぎ目を森の土台の上に）
- 流れの層は、角のまわりのマスのどれかが森でなければ「なし」（草原と同じ）。境の手前で消える

## 2. 絵の中身

- **土台**：苔の床。苔の床の帯（3〜4 個、縁まで）と小さいむら 400 個を、**苔のクッション（2〜4 幅・2〜3 高さの丸い塊）**で描く。落ち葉・針葉の印を不ぞろいな間隔（投げ込み）で 160 個、模様の縁に 40 個足す（256 点の縁に印のない帯を作らない）。夏＝針葉の束と苔のこぶ、秋＝針葉の束・苔のこぶ・落ち葉の吹きだまり（4〜7 枚、くすんだ橙）、冬＝雪の上の柔らかい雪の盛り上がり（7×3、明るい上と青い影）。冬のむらは草原の冬と同じ "fine" ランプ（明るさの差 11 前後）。小枝・冬の小枝の印は入れない（試したところ、赤い線の散らばり・1 点の黒い点になった）
- **流れの形**：夏・秋は苔のクッション（第 2 版：6〜9 幅・3〜4 高さで数を 40 に減らし、1 つのクッションを 1 色の 255 にした。先と体の境の段を作らない）、冬は吹きだまりの筋（体 214・先 255）。置き方・行と列のならし・小さい塊を消す手順は草原と同じで、最後に縁に触れない 1〜3 点の塊を消す
- **つなぎ目**：**中は土台のマスの絵そのもの**（第 3 版。(mask, v) ごとに 8 模様×16 マスから 1 枚を `edge_base_pick` で決め、曲線で切る。同じ mask の中では v ごとに別の模様から取る（検査 3 回目の P3-3。52 枚の元のマスは 46 種類）。土台と同じむら・クッション・印なので、模様の量が土台と同じ）。曲線で切れて透明な所に接した 1〜3 点の同じ色の切れは、内側のとなりの色に直す。縁の 3 点はクッションの縁（光の側は明るく、影の側は暗く）、境の外に苔の小さい塊（2×2〜3×2）。**冬は縁の線なし**（土台の雪の模様が切り口まで続く）、外の青い影もなし
- **木**：針葉樹は草原の針葉樹の描き方（段ごとのぎざぎざのすそ、全体を 1 つの円すいとして塗る、上の段の影、2 点の針葉の房）を、大きさ・段の数・幅・垂れ方・段の間のすき間・色で 3 種に分けた。**白樺は第 2 版で描き直した**：細く高い幹（7→2 点、少し右へ傾く、高さの 80%）、上へ向かう 7 本の細い枝（38〜70°、左右交互で高さは不ぞろい）、枝先と幹の上の小さく明るい葉の塊（rx 7〜12、右に多い）、白い樹皮に黒い横の模様。冬は同じ骨組みの枝に小枝。**雪は載せない**（第 3 版で文を絵に合わせた。絵は第 2 版から雪 0 点。検査 2 回目の所見：白い樹皮なので見た目の害は小さい）。**冬の spruce**（第 3 版）：段が垂れて重なり、上の面がほとんどないので、上の段の下から見える各段の上の面（段の外寄り、左の光の側に多く、右の影の側はすき間をあけて）に 1〜2 行の雪を載せる。4 点未満の切れは葉に戻す
- **小物**：シダ（7 本の葉、揺れ 2 コマ。**冬は雪の盛り上がりから枯れた葉先が 3 本出る**）、ベニテングタケ（2×2 の白い斑点、冬は雪の帽子）、苔の倒木（切り口の年輪、上に苔、冬は雪）、苔の岩（草原の岩・中に苔、冬は雪）、地面の根（冬は太い所だけ雪）
- 冬の雪：最後に、4 点未満の雪のかけら（雪の 1〜6 段、輪郭を除く）、つぎに明るい雪（4〜6 段）だけの 4 点未満の切れ、もう一度 1〜6 段の順に、まわりのいちばん多い雪でない色に直す

## 4. 画像メモリ（STYLE 10.2 の数え方：64×64 のマスは詰め方のむだなし。第 2 版で直した）

| 1 季節分（RGBA） | 森だけ | 草原との境（森＋草原） |
|---|---|---|
| 地面（土台 128・つなぎ目 52・流れの形 104） | 4.653 MB | **9.306 MB**（枠 10.0 MB、余り 0.69 MB） |
| 木・小物（`forest.pine` は `pine_s.0` と同じ絵なので数えない） | 0.948 MB（冬 0.805） | 森＋草原 **2.029 MB**（冬 1.398）：枠 2.0 MB をわずかに超える |

- **境での木・小物の収め方**（第 3 版で書き直し）：境では、草原の木・小物のうち**針葉樹 `plains.tree.v3.pine`（3 コマ、0.230 MB）を読まない**（森の針葉樹がある）。境の木・小物は 1.799 MB（冬 1.168）で枠に入る
  - **置き方の決まり（第 3 版の 2 回目の直し。統括の決定＝検査 3 回目の案 1）**：**森の地方の四角にかかるチャンクから、チャンクで数えて 2 以内のチャンクには、草原の松 `plains.tree.v3.pine` を置かない**
    - チャンク：32×32 マス（`gameView.js` の `CHUNK = 32`）。チャンク (cx, cy) はマス `cx*32 … cx*32+31`、`cy*32 … cy*32+31`
    - 森の地方の四角：`world.js` の `def.regions` の `tx, ty, tw, th`（地方の地面の配列全体の外接の四角。東の部屋の列を含む。森のセルそのものではない）
    - 「かかるチャンク」：`gameView.chunkBundles` と同じ判定（`r.tx < x0 + 32 && r.tx + r.tw > x0 && r.ty < y0 + 32 && r.ty + r.th > y0`）で森の束を返すチャンクの集まり A
    - 置かない所：A のどれかとのチャンクの距離（チェビシェフ、`max(|cx − ax|, |cy − ay|)`）が 2 以下のチャンクにある草原のセル。最大で、A を 2 チャンクずつ広げた四角になる
    - 森の地方の中に草原のセルがあっても、そこは A の中なので置かない
  - **根拠（ゲームの読み込みの決まり）**：
    - 地方の木・小物の絵は、地方の束（`region:<id>`）としてチャンクごとに読む。チャンクが要る束は、そのチャンクにかかる地方のもの（`chunkBundles`）。チャンクの外 1 セルの輪で読むのは、となりの地方の「ground:」の束だけで、木の絵は入らない（`ringBundles`）
    - 作るチャンク：画面＋4 マス（`chunkRange.js` の `CHUNK_LOAD_MARGIN_TILES = 4`、下は＋64 点）。消すチャンク：画面＋12 マスの外に出た時だけ（`CHUNK_KEEP_MARGIN_TILES = 12`）
    - 森の v3 の束（`v3:forest:<季節>`・`v3:forest:flow`）は、それを要るチャンク（A のチャンクと、森の地面を持つチャンク）が作られている間だけ持つ。先読みした束を地方の四角が画面から 32 マス以内の間も持ち続ける決まり（`gameView.regionNear`）は `region:<id>` の束だけのもので、v3 の束には効かない
