# 絵の差し替えガイド（P11.5）

ゲームの絵は、1 枚ずつ「名前」で呼ばれています（例：`player.walk.down.0` ＝主人公・下向き・歩き 1 コマ目）。
**`src/art/` に `名前.png` を置くと、その絵だけが差し替わります。** 置いていない絵は今の仮の絵のままなので、少しずつ入れ替えられます。

## 主人公について

主人公の絵は、`docs/hero/HERO_DESIGN_SPEC.md`（デザインの基準）と `docs/hero/P12_ASSET_LIST.md`（作る絵の一覧）に合わせ、`src/art/characters/hero/` に置きます。

## 下絵セット

- `docs/art-kit/` に、今の絵が **ちょうどの大きさの PNG** で全部（266 枚）入っています。上から描いて、同じ名前で保存すれば OK
- 一覧（名前・大きさ・基準点）は `docs/art-kit/LIST.md`
- フォルダーは読み込みのまとまりごと（`base`＝どこでも使う、`region-forest`＝森の地方だけ、`season-winter`＝冬だけ、など）

## 決まりごと

| | |
|---|---|
| 形式 | PNG（背景は透明） |
| 大きさ | 1 ドット＝ゲーム内の 1 ドット（拡大して保存しない）。地面は 1 マス 16×16 |
| 地面・崖（基準点「左上」） | **大きさを変えられない**（違うとそのファイルは使われず、仮の絵のまま） |
| 物・キャラ（基準点「足元」） | 大きさは自由。下の真ん中が足元（地面に立つ位置）になる |
| 効果（基準点「中心」） | 大きさは自由。真ん中が基準 |
| 色 | 自由（仮の絵の色に合わせなくてよい） |
| アニメ | `.0` `.1` `.2` … がコマ。コマ数は今と同じにする |

- 当たり判定は絵と別に決めてあるので、物を大きく描いても通れる場所は変わりません
- 季節の絵（`autumn.〜` `winter.〜` `spring.〜`）は、置かなければその季節の仮の絵のままです。夏は季節なしの名前の絵が使われます
- `px` は線や帯を描くための 1 色の点なので、差し替え不要です

## 渡し方

どちらでも大丈夫です。

1. **GitHub に直接**：リポジトリの `src/art/` で「Add file → Upload files」（フォルダーはそのままでも OK）。ブランチを作って上げてもらえれば、こちらで確認して入れます
2. **ファイルを送る**：まとめて送ってもらえれば、こちらで置きます

## 注意（リポジトリは公開です）

`src/art/` に入れた絵は、公開リポジトリと公開版のゲームから誰でも取り出せます。
**再配布してよいライセンスの素材（自作、または再配布可の購入素材）だけ**にしてください。購入素材で再配布が禁止されている場合は、別の方法を相談させてください。
