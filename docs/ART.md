# 絵の差し替えガイド（P11.5）

ゲームの絵は、1 枚ずつ「名前」で呼ばれています（例：`player.walk.down.0` ＝主人公・下向き・歩き 1 コマ目）。
**`src/art/` に `名前.png` を置くと、その絵だけが差し替わります。** 置いていない絵は今の仮の絵のままなので、少しずつ入れ替えられます。

## 本番の絵の規格（2026-11-05 決定）

**本番の絵は「ゲーム内の 1 ドットにつき、絵の 2 ドット」で描きます。** 地面 1 マス（ゲーム内 16）は絵では **32×32**、主人公は **32×56**（ゲーム内では幅 1 マス・高さ 1.75 マス）です。
ゲームの仕組み（地図のマス、当たり判定、移動の速さ、攻撃の範囲、カメラの動き）はゲーム内の単位のままなので、絵を描き直しても遊び方は変わりません。本番の絵が 1 枚でも入ると、画面も 2 倍の細かさで描かれ、細かい絵がつぶれずに出ます。

| 種類 | 絵の大きさ（ドット） | 基準点 | 主人公との比べ方 |
|---|---|---|---|
| 地面・水・床（1 マス） | **32×32**（固定） | 左上 | — |
| 崖の側面 | 32×8 ／ 32×16（固定） | 左上 | — |
| 主人公 | **32×56**（全部の動きで同じ枠） | 足元 | 基準 |
| 村人・人型の敵（弓兵など） | **32×56**（主人公と同じ枠） | 足元 | 大人は主人公と同じくらい、子どもは低く（枠は同じ） |
| 獣の敵 | 32×26 前後（枠は動き全部で同じに） | 足元 | 主人公の腰〜胸の高さ |
| ボス（核） | 64×60 前後 | 足元 | 主人公の 2 倍以上 |
| 建物 | 幅はマスの倍数（家は幅 96）。高さは扉＋屋根で 112 前後（足元から上へ伸ばしてよい。占めるマスは変わらない） | 足元 | **扉・門の高さは 64 以上**（主人公 56 より高く。`obj.door` も同じ） |
| 家具・宝箱・壺など | 仮の絵の 2 倍が目安（`LIST.md`） | 足元 | 机は主人公の腰、棚は頭くらい |
| 木 | 32×56 前後（森の針葉樹は 32×60） | 足元 | 主人公より高く |
| 持ち物のアイコン | 20×20（仮の絵の 2 倍） | 足元 | — |
| 効果（剣の軌跡・矢など） | 仮の絵の 2 倍が目安 | 中心 | — |

- 当たり判定は絵の大きさと別で、足元を基準に決まっています（主人公は幅 10・高さ 6 のまま）
- **小さい絵を拡大しただけのものは完成品にしない**（最初からこの解像度で描く）
- 比べ方：`?hd=0` を付けると本番の絵を使わない今までの画面、付けないと本番の絵の画面（`?hero=test` で大きさ確認用の仮の主人公）

## 主人公について

主人公の絵は、`docs/hero/HERO_DESIGN_SPEC.md`（デザインの基準）と `docs/hero/P12_ASSET_LIST.md`（作る絵の一覧）に合わせ、`src/art/characters/hero/` に置きます。

## 下絵セット

- `docs/art-kit/` に、全部の絵（266 枚）が **本番の大きさの PNG** で入っています。中身は仮の絵を拡大しただけの**大きさの目安**です（キャラクターは 32×56 の枠の下の中央に置いてあります）。完成品にはせず、その大きさで描き直して、同じ名前で保存してください
- 一覧（名前・作る大きさ・基準点）は `docs/art-kit/LIST.md`
- フォルダーは読み込みのまとまりごと（`base`＝どこでも使う、`region-forest`＝森の地方だけ、`season-winter`＝冬だけ、など）

## 決まりごと

| | |
|---|---|
| 形式 | PNG（背景は透明） |
| 大きさ | 上の「本番の絵の規格」。絵 2 ドット＝ゲーム内 1 ドット |
| 地面・崖（基準点「左上」） | **大きさを変えられない**（32×32 など。違うとそのファイルは使われず、仮の絵のまま） |
| 物・キャラ（基準点「足元」） | 大きさは自由。下の真ん中が足元（地面に立つ位置）になる |
| 効果（基準点「中心」） | 大きさは自由。真ん中が基準 |
| 色 | 自由（仮の絵の色に合わせなくてよい） |
| アニメ | `.0` `.1` `.2` … がコマ。今あるコマ数は変えない（増やす分は P12 で決める） |

- 当たり判定は絵と別に決めてあるので、物を大きく描いても通れる場所は変わりません
- 季節の絵（`autumn.〜` `winter.〜` `spring.〜`）は、置かなければその季節の仮の絵のままです。夏は季節なしの名前の絵が使われます
- `px` は線や帯を描くための 1 色の点なので、差し替え不要です

## 渡し方

どちらでも大丈夫です。

1. **GitHub に直接**：リポジトリの `src/art/` で「Add file → Upload files」（フォルダーはそのままでも OK）。ブランチを作って上げてもらえれば、こちらで確認して入れます
2. **ファイルを送る**：まとめて送ってもらえれば、こちらで置きます

## 注意（リポジトリは公開です）

`src/art/` に入れた絵は、公開リポジトリと公開版のゲームから誰でも取り出せます。
**再配布してよいライセンスの素材（自作、または再配布可の購入素材）だけ**にしてください。購入素材で再配布が禁止されている場合は、別の方法を相談させてください。
