## 行き方

島の南の浜から砂の道を南へ。風の草原に入ってすぐ北側に「風見の村」がある（家が 4 軒）。

## チェックリスト

- [ ] 村に住人が 5 人いて、歩き回っている。近づくと止まってこちらを向く
- [ ] 住人の前で「攻撃」（または画面下の「話す」）で会話が始まる。タップで文字が進む
- [ ] 村長に 2 回話すと「なくしたお守り」を頼まれる（選択肢が押せる）
- [ ] 持ち物の「クエスト」に「進行中」で出る
- [ ] 荒野でお守りを拾うと「報告できる」になり、村長に報告すると星貨とお礼がもらえる
- [ ] 雑貨屋で買い物・売り物ができる（星貨の増減が正しい）
- [ ] 保存して「つづきから」で再開しても、クエストの状態が残っている
- [ ] 会話の文字や選択肢が小さすぎず、押しやすい
- [ ] エラー表示（赤いボタン）が出ていない

## 判定

- [ ] 合格。P10 へ進む
