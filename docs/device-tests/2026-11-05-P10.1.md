## 行き方

島の南の浜から砂の道を南へ。風の草原に入ってすぐ北側の「風見の村」。家が 4 軒ある。

## チェックリスト

- [ ] 家の扉の前で上に歩くと、家の中に入れる（家の名前が出る）
- [ ] 玄関マットの上で下に歩くと、外の扉の前に戻る
- [ ] 雑貨屋：カウンターの向こうの店主に、カウンター越しに話しかけて買い物できる
- [ ] 料理番の家：かまどの前で「料理する」が出て、料理できる
- [ ] 長老の家：お守りを届けたあと、棚にお守りが飾られている
- [ ] 宿：ベッドの前で「眠る」→「朝まで眠る」で 6:00 になり、ハートが全回復する

- [ ] 壁を通り抜けたり、壁を登ったりできない
