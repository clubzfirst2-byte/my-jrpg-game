## チェックリスト

- [ ] 島の 3 か所の「光る石柱」に北向きに入ると、試練の部屋に入れる。入ると能力が手に入る
- [ ] 灯台塔の頂上の祭壇に触れると「共鳴」が手に入る
- [ ] 「能力」ボタンで使える。⇄ で切り替えられる
- [ ] 灯りの試練：暗い部屋で、灯火（または火矢）で扉が開く
- [ ] 重さの試練：念動（または剣で押す）で箱を板に乗せ、もう 1 枚に乗ると扉が開く
- [ ] 奈落の試練：蔓結びで穴に橋をかけて渡れる（または火矢・共鳴で開く）。穴に落ちると手前に戻る
- [ ] 試練の宝箱から星の欠片が出て、持ち物の「能力」でハートかがんばりを増やせる
