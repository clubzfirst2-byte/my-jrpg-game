## 場所

- 双火の試練：囁きの森の光る石柱
- 暗がりの試練：赤砂の荒野の光る石柱
- 水鏡の試練：鏡湖と群島の西岸の光る石柱
- 白嶺の坑道：白嶺山脈の崖に開いた洞穴

## チェックリスト

- [ ] 光る石柱に上へ歩くと試練の部屋に入れる。南の端で下へ歩くと外へ出られる
- [ ] 双火の試練：火矢（かがり火越し）か炎の剣で 2 つの燭台を灯すと扉が開く
- [ ] 暗がりの試練：箱を床に載せて、光の受け口を照らすと扉が開く
- [ ] 水鏡の試練：火矢・泳いで渡る・共鳴のどれかで扉が開く
- [ ] 白嶺の坑道：階段で地下 3 階まで下り、宝箱（星のかけら）を取れる
- [ ] エラー表示（赤いボタン）が出ていない
