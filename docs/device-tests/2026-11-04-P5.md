## ライティングの負荷（DESIGN.md ロードマップ P5 の完了条件）

同じ場所で 2 回ずつ「計測 30秒」を取り、平均 FPS と「遅い 5%」を比べます。計測パネルの「ライト」の行に、1 フレームの描画時間が出ます。

| 条件 | URL | 平均 FPS | 遅い 5% | ライト |
|---|---|---|---|---|
| 昼（ライトなし） | `?debug=1&map=island&time=10` | | | なし |
| 夜（ライトあり） | `?debug=1&map=island&time=22` | | | ms |
| 夜（ライトを消す） | `?debug=1&map=island&time=22&light=0` | | | なし |
| 雷雨 | `?debug=1&map=island&weather=storm&time=15` | | | ms |

## チェックリスト

- [ ] 左上に時刻と天気が出て、時間が進む（1 分で 1 時間）
- [ ] 夕方は赤く、夜は暗くなり、たき火・かがり火・燃えている所が光る
- [ ] 雨が降ると画面に雨が見え、燃えている火が消える
- [ ] 雨の中で崖を登ると、ときどき滑り落ちる
- [ ] 雷雨で、落ちる前に地面が点滅し、雷が落ちる
- [ ] 草を燃やして、その上を滑空すると上昇する
- [ ] 洞窟の中では雨が見えない
- [ ] 「つづきから」で、保存したときの時刻から再開する
