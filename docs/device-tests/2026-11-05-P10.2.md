## 確認のしかた

季節は 7 日（実時間で約 2 時間 48 分）ごとに変わるので、確認用の URL で各季節を開く。

- 春：https://clubzfirst2-byte.github.io/my-jrpg-game/?map=world&season=spring
- 秋：https://clubzfirst2-byte.github.io/my-jrpg-game/?map=world&season=autumn
- 冬（雪）：https://clubzfirst2-byte.github.io/my-jrpg-game/?map=world&season=winter&weather=snow

（`?map=` を付けた URL は保存しない）
