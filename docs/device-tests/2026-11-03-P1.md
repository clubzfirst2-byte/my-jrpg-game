## 内部解像度の比較と決定（DESIGN.md 2.1）

| 候補 | 評価 |
|---|---|
| 180 | 少し近すぎる |
| 216 | 採用 |
| 270 | 遠すぎる |

**決定：216**。理由：遠くの探索目標が見えること（DESIGN.md 5.9）、P2 以降の滑空・高所からの見渡し、戦闘での敵の接近や弓の射程、操作ボタンが画面の隅を覆うことを考え、180 より広い視野を優先した。キャラクターを大きく見せたい場面は、P3 以降でカメラの自動ズーム（戦闘・屋内で寄る、高所・滑空で引く）として検討する。

## 気づいたこと

- 横向きの Safari では、アドレスバーなどで表示領域の高さが 393 → 339 に減り、内部解像度も 236 → 204 になる。ホーム画面に追加して起動すると全画面になる。最終的にはホーム画面からの起動（PWA）を前提とする
- P0 と比べて JS 処理時間が 1.9 → 0.5 ms に減った（地面の静的なタイルを 1 枚のテクスチャにまとめた効果）
