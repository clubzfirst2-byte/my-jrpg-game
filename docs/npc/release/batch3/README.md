## 星環の姫（`princess`）
物語の中心人物です。顔・髪・輪郭は、主人公と並べて何度も見直しました（`03b_princess_hero.png`）。

| 項目 | 描いたもの |
|---|---|
| 背 | 主人公より 2 ドット低い（頭の上の輪郭線が 2 行目。主人公は 0 行目）。単体テストで確認 |
| 髪 | 長い銀髪。影は冷たい青。前髪はまっすぐ切りそろえ、真ん中だけ分ける。両側の一房を細い三つ編みにして肩の前（ケープの上）に垂らし、先を金の留め具で結ぶ |
| 後ろ髪 | 正面：体の両側を縁取って腰まで下りる。毛先の長さはそろえていない。背面：短いケープの青い帯が髪を横切り、その下から髪がまた出て、腰で不ぞろいの毛先になる（デザイン案どおり）。横向き：背中に沿って腰まで流れる |
| 目 | 主人公と同じ描き方（まつげの線・2 色の瞳・光）。目じりを 1 ドット上げた。**夜明け前の空の色**：上が濃い藍、下が明るい空色。光は白い 1 ドット。左右の目とも、光は光源（左上）の側にある |
| 顔 | 主人公より少し細いあご、小さな鼻（影 1 ドット）、うすい頬の赤み。口は右の端だけ少し上がる、やわらかい笑み |
| 額飾り | 金の細い輪が頭を一周する（背面でも見える）。正面の中央に、**主人公のペンダントと同じ形・同じ色の石**（青い四方の星・金の枠）。石の光は、主人公のペンダントと同じ周期で動く |
| 衣装 | 白いひざ丈の旅の服（すそは軽く広がり、青い縁取り）、白い長靴下、やわらかい茶の短いブーツ（折り返し付き） |
| ケープ | 深い星の青。正面は胸まで（すそは V 字）、背面は腰の上まで。縁は金。首元に金の星の留め具 |
| 帯 | 腰の青い帯に、金の細い線が上下しながら走る（星脈）。線の上に明るい点（星）が 1 つ |
| 手 | 何も持たない。体の前で両手を軽く重ねる（右手が上）。歩くときも腕は振らない |
| 腕輪 | **左手首**に細い金の腕輪。正面では画面の右側の手首に見える。右向きでは奥の手首に少しだけ、左向きでは手前の手首にはっきり見える |
| 主な色 | 白・深い星の青。サブ：金・銀。差し色：額飾りの青い石 |

- 物語では、姫は記録の石のところに半透明の「写し身」として現れる。透明度や色はゲーム側で変える前提のため、**絵は通常どおり不透明（アルファは 0 か 255 のみ）**で描いた
- 名前は付けていない（ID は `princess`）

## 旅人（`traveller`）
| 項目 | 描いたもの |
|---|---|
| 背 | 9 人で**いちばん高い**。帽子の山が枠の 0 行目に届く（単体テストで確認） |
| 顔 | 年配で、性別を限らない（ひげ・化粧なし）。細長い日焼けした顔、頬の深い線、細い鼻（片側の影）。口は片方の端がわずかに上がった、少し謎めいた形 |
| 目 | ほぼ線の細い目。瞳は帽子の影の中に灰緑の 1 ドット。まぶたの下に年齢の影 |
| 髪 | 灰色。こめかみに白髪の筋。後ろで 1 本に結び（えんじのひも）、背中の上まで垂れる。背面では、髪が結び目に向かって流れる |
| 帽子 | つば広（枠の幅いっぱい近く）。えんじの帯 |
| 衣装 | くすんだ茶の長い外套（ふくらはぎまで、前が開く、すそはすり切れて不ぞろい）。中に灰色の上着、濃い色の細いズボン、使い込んだブーツ |
| 襟巻 | えんじ。首に巻き、**片方の端を胸の右側に垂らす**。待機中も歩行中も揺れる |
| 荷物 | 背負い袋（赤みのある革。ポケットと金具）と、上に巻いた寝袋（くすんだ緑）。正面では寝袋の両端が肩の外に出る。横向きでは寝袋の巻いた端（渦巻き）が見える |
| 杖 | 長くまっすぐな杖を、**右手で体の横に立てて持つ**（長老の杖とは形も持ち方も違う）。上の方に水の瓢箪を結ぶ。歩くときは杖を地面に突きながら前へ出す。待機の 3 コマ目に握り直す |
| 姿勢 | 横向きで頭が胸より 1 ドット前に出る、少し前かがみの立ち方 |
| 主な色 | くすんだ茶・灰。サブ：えんじ。差し色：瓢箪の黄土、寝袋の緑 |

## 左向き
2 人とも、片側にだけある物があるため、**左右反転ではなく別に描きました**（単体テストで、左向きのどのコマも右向きの反転と違うことを確認）。
- 姫：左手首の腕輪（左向きでは手前に見える）
- 旅人：右手の杖と瓢箪（左向きでは体の奥側）、胸の右側に垂れた襟巻の端（左向きではほぼ隠れる）

## アニメーション
- 待機（4 コマ、どの方向もすべて違う絵）
  - 姫：呼吸（胸から上が 1 ドット上がる）、髪の先・三つ編みの揺れ、額飾りの石の光（主人公のペンダントと同じ周期）、4 コマ目にまばたき。背面では額飾りの輪の光が移る
  - 旅人：呼吸、襟巻の端と外套のすその揺れ、3 コマ目に杖を握り直す、4 コマ目にまばたき
- 歩行（6 コマ）
  - 姫：歩幅は小さめ。すそと髪の先が遅れて揺れる。手は前で重ねたまま
  - 旅人：歩幅が大きい。杖を突きながら前へ出す。外套のすそと襟巻の端が揺れる。体が上下する

## 改善点と未解決事項
- **E2E の枚数の期待値**：`tests/e2e/npc-release.spec.js` は、NPC の絵の枚数を 280 枚として数えている（38・129・168・185 行目：`248 + 280` と `280`）。この回で 360 枚になったため、E2E ではこの 4 か所が失敗するはず。今回の指示の範囲外のファイルなので変えていない。360 に直す必要がある
- 姫の背面：長い髪のかたまりが大きく、頭の形が少し単調に見える。毛の流れはつけたが、さらに分け目や毛束を増やす余地がある
- 姫の正面の手：前で重ねた手は 6×3 ドットで、離れて見ると細部は分かりにくい（「手に何も持たない」ことは伝わる）
- 旅人の正面：寝袋の両端が肩の外に出る形は、遠目には肩当てのようにも見える。端の渦巻きを強める余地がある
- 旅人の顔は日焼けの色のため、帽子の影と合わせて暗めに見える。明るい場所での見え方はゲーム画面で確認してほしい
- 写し身の表現（半透明・色）は、ゲーム側の作業として残っている
- 2 人の配置・会話は未定
