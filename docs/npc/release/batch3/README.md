## 星環の姫（`princess`）
物語の中心人物です。顔・髪・輪郭は、主人公と並べて何度も見直しました（`03b_princess_hero.png`）。

| 項目 | 描いたもの |
|---|---|
| 背 | 主人公より 2 ドット低い（頭の上の輪郭線が 2 行目。主人公は 0 行目）。単体テストで確認 |
| 髪 | 長い銀髪。影は冷たい青。前髪はまっすぐ切りそろえ、真ん中だけ分ける。両側の一房を細い三つ編みにして肩の前（ケープの上）に垂らし、先を金の留め具で結ぶ |
| 後ろ髪 | 正面：肩の後ろから体の両側を縁取って腰（38 行目）まで下りる。毛先の長さはそろえていない。背面：3 本の大きな房。短いケープの青い帯が髪を横切り、その下から髪がまた出て、腰で不ぞろいの毛先になる（デザイン案どおり）。ケープの両側にも腰まで下りる。横向き：同じ房が背中に沿って腰まで流れる |
| 目 | 主人公と同じ描き方（まつげの線・2 色の瞳・光）。目じりを 1 ドット上げた。**夜明け前の空の色**：上が濃い藍、下が明るい空色。光は白い 1 ドットで、**左右の目とも瞳の右上**にある（主人公の目の光と同じ側） |
| 顔 | 主人公より少し細いあご、小さな鼻（影 1 ドット）、うすい頬の赤み。口は右の端だけ少し上がる、やわらかい笑み |
| 額飾り | 金の細い輪が頭を一周する（背面でも見える）。正面の中央に、**主人公のペンダントと同じ形・同じ色の石**（青い四方の星・金の枠）を、小さな金の輪（星環）の中にはめた。石の光は、主人公のペンダントと同じ周期で動く |
| 衣装 | 白いひざ丈の旅の服（すそは軽く広がり、青い縁取り）、白い長靴下、やわらかい茶の短いブーツ（折り返し付き） |
| ケープ | 深い星の青。正面は胸まで（すそは V 字）、背面は腰の上まで。縁は金。首元に金の星の留め具。光は左上から：左肩に明るい面、斜めのひだ |

## 左向き
- **旅人**：右手の杖と瓢箪（左向きでは体の奥側）、胸の右側に垂れた襟巻の端（左向きではほぼ隠れる）があるため、**右向きの反転ではなく別に描いた**（1 コマあたり約 140 ドット違う）
- **姫**：**右向きを左右反転し、腕輪を手前の手首に描き足したもの**（20 コマすべてで、反転との違いは腕輪の 4 ドットだけ。単体テストで確認）。三つ編みは両側、手は体の前で重ねているので、反転しても不自然にならない（スタイルガイド 19 番は反転を認めている）。光の向きも反転するので、左向きだけは光が右上から来る

## アニメーション
- 待機（4 コマ、どの方向もすべて違う絵）
  - 姫：呼吸（胸から上が 1 ドット上がる）、髪の先・三つ編みの揺れ、額飾りの石の光（主人公のペンダントと同じ周期）、4 コマ目にまばたき。背面では額飾りの輪の光が移る
  - 旅人：呼吸、襟巻の端と外套のすその揺れ、3 コマ目に杖を握り直す（杖は動かない）、4 コマ目にまばたき
- 歩行（6 コマ）
  - 姫：歩幅は小さめ。すそと髪の先（正面では体の両側の毛先、背面ではケープの下の毛先）が遅れて揺れる。手は前で重ねたまま
  - 旅人：歩幅が大きい。杖を突き、追い越し、持ち上げて前へ出す。外套のすそと襟巻の端が揺れる。体が上下する
