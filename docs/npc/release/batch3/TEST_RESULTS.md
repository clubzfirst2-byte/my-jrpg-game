## 単体テスト `tests/unit/npcRelease.test.js`（9 人に広げた内容）

| 確認項目 | 内容 |
|---|---|
| 枚数・名前 | 9 人で 360 枚（第 3 回で 80 枚を追加：`princess` 40 枚・`traveller` 40 枚）。名前の規則どおりで、ほかのファイルはない |
| 第 1 回・第 2 回が変わっていない | 第 1 回の 120 枚、第 2 回の 160 枚が、固定したハッシュ（SHA-256）と 1 バイト単位で同じ |
| 画像の仕様 | すべて 32×56、8 ビット RGBA、四隅は透明、半透明なし（姫も不透明で描いている） |
| 足元 | 全コマで足が下から 2 行以内にあり、中央にある。待機中は足の裏が動かない（旅人の杖も、待機中は動かさない） |
| 動き | 待機 4 コマ・歩行 6 コマが、どの方向もすべて違う絵 |
| 左向き | 左右反転ではなく、別に描いた絵（姫の腕輪、旅人の杖・瓢箪・襟巻の端） |
| 体格 | **旅人がいちばん高い**（枠の 0 行目。9 人のだれよりも低くない）。**姫は主人公より 2 ドット低い** |
| 使い回しの禁止 | 9 人のどの 2 人も、正面の輪郭が 80 ドット以上違う |
| 輪郭の色 | 9 人とも、輪郭に濃い色がある（主人公と同じ描き方） |
| コマの選び方 | `princess`／`traveller` の ID の NPC は製品版の絵を使う。製品版の絵がない ID（テストでは `stranger`／`pilgrim`）は仮の絵のまま |
