## 追加したテスト

### 単体テスト `tests/unit/npcRelease.test.js`（13 件）
| 指示書の確認項目 | テスト |
|---|---|
| 全 120 枚が存在する／ファイル名が規則どおり | 3 人 × (待機 4 ＋歩行 6) × 4 方向がそろっていて、ほかのファイルはない。名前は `npc.<ID>.<idle\|walk>.<方向>.<番号>` |
| 画像サイズ／PNG の透過 | すべて 32×56、8 ビット RGBA。四隅は透明。半透明のふちはない |
| 足元の位置が統一 | 全コマで、足が下から 2 行以内にあり、左右の中央にある。待機中は足の裏が動かない |
| 待機・歩行が動く | 各サイクルの全コマが違う絵 |
| 左向き | 持ち物を同じ手に持ったまま別に描いている（右向きの単純な反転ではない） |
| 主人公との大きさ | 長老がいちばん小さい（主人公より 4 ドット以上低い）。見張りは雑貨屋より高く、主人公とほぼ同じ |
| 色 | 輪郭線の濃い色がある（主人公と同じ描き方） |
| どのコマを出すか（`npcFrameKey`） | 立っているときは待機（4 コマ、時間で進む）。歩いているときは歩行（6 コマ、歩いた時間で進む）。止まったらすぐ待機に戻る。向きを反映する。製品版の絵がない人物は仮の絵のまま。2 人の呼吸がそろわない |

### E2E `tests/e2e/npc-release.spec.js`（6 件）
| 指示書の確認項目 | テスト |
|---|---|
| 4 方向が正しく表示／主人公との大きさ | `?hero=release` で、長老・見張り・雑貨屋が製品版の絵（16×28）で表示される。料理人（仮の絵）は 16×16 のまま。絵の読み込みの警告・エラーはない |
| 待機・歩行のアニメーション | 立っている長老の待機のコマが変わる。歩く見張りは歩行のコマで、向きが進む方向と同じ。止まると待機に戻る |
| 会話中に主人公を向く／前後関係 | 話しかけると見張りが主人公の方（下）を向き、その向きの絵で表示される。各 NPC の描画の順番が足元の位置どおり |
| 既存のショップが動く | お店に入り、カウンター越しに製品版の雑貨屋と話し、お店の画面が開いて閉じる |
| 既存の NPC 機能が壊れていない | `?npc=placeholder` で仮の絵に戻る。通常の起動（main は主人公も仮の絵）は変化なし（細かさ 1、置き換え 0）。`?npc=release` で NPC だけ製品版にできる |
| iPhone 横画面 | iPhone 15 横向きの画面で、3 人と主人公が表示される（画面写真 `05`〜`08`） |
