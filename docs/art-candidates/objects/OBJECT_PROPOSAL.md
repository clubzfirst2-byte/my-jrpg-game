## 絵柄の決まり（全部に共通）

主人公と同じ描き方です。

1. **1 つの材料に 5 段階の色**（いちばん暗い＝ふち、影、地の色、明るい面、つや）
2. **光は左上から**。左と上の面が明るく、右と下が暗い
3. **ふちの線は材料ごとの一番暗い色**（黒一色にしない）。木なら焦げ茶、石なら濃い灰、火なら濃い赤
4. **大きな絵を縮めたり、小さい絵を拡大したりしない**。最初からこの大きさで 1 ドットずつ置く
5. 見下ろしの角度は主人公と同じ（上の面が少し見え、前の面が大きく見える）
6. 地面の影は絵に入れない（ゲーム側の `fx.shadow` に任せる。見本の画像の影も確認用に足しただけ）

### 種類ごとの決まり

| 種類 | 決まり |
|---|---|
| 建物 | 幅はマスの倍数。屋根・壁・土台の 3 段で作る。扉は高さ 64 以上で、下の真ん中のマス（入口のマス）に合わせる。窓・扉・柱などの部品は家どうしで使い回し、屋根の色や壁の材料で家ごとに変える |
| 家具・小物 | 主人公との比べ方は `ART.md` の表どおり（机は腰、棚は頭）。木は 2 種類（明るい「木箱の木」、赤みの「家具の木」）を使い分け、金具は主人公の金・鋼と同じ色 |
| 仕掛け（スイッチ・記録の石など） | **石と鋼でできた「古い仕掛け」**で統一。働いている印は**青い光（主人公の首飾りの宝石と同じ青）**。暗い彫り → 光る彫り、で 2 コマの違いが一目でわかる |
| アイコン | 20×20 に収め、ふちの線で背景から切り離す。斜めに置く長い物（剣・弓・矢）は左下→右上。草地の上でも暗い UI の枠の上でも読めるよう、明るい面を必ず入れる |
| 効果（火・軌跡・光） | 光る物はふちを黒くしない（火は濃い赤、軌跡は青）。中心ほど明るい（白 → 黄 → 橙 → 赤）。軌跡や光は外側を半透明にしてよい |

### 2 コマで状態を見せる決まり

| 状態の変化 | 見せ方 |
|---|---|
| 閉 → 開（宝箱など） | 形（影絵）を変える。ふたの位置が変わり、中の暗い穴が見える |
| 消 → 点（記録の石・受け皿・燭台など） | 形は同じ。**彫りや火皿の色**だけを、暗い色 → 青（または火の色）に。点いた方は周りの石が少し色づく |
| 未 → 済（踏むスイッチ・センサー） | 高さを変える（浮いている → 沈む）＋青い光 |
| 動き（たき火・火・かがり火） | 2 コマで炎の先が左右に揺れ、高さが少し変わる。火の粉の位置を変える |

## 色

主人公と同じ材料（木・金・鋼・革・青い宝石・骨）はそのまま共通の色を使い、世界全体が同じ絵に見えるようにしています。新しく足した材料は次のとおりです（すべて 5 段階、`tools/object_release/draw.py` の `RAMPS`）。

| 材料 | 使う所 | 色の方向 |
|---|---|---|
| 瓦（roof） | 家の屋根 | 赤茶（草の緑と反対の色で、村が遠くから見つけやすい） |
| しっくい（plaster） | 家の壁 | 温かい白 |
| 柱の木（timber） | 家の柱・窓枠 | 濃い茶 |
| 石（stone） | 土台・記録の石・スイッチ・たき火の石 | 少し青みの灰 |
| 家具の木（chestwood） | 宝箱・扉 | 赤みの茶 |
| 木箱の木（crate） | 木箱 | 明るい黄土色 |
| 素焼き（clay）・釉薬（glaze） | 壺・窓の雨戸 | 素焼きの橙・青緑 |
| 光（glow） | 仕掛けが働いている印 | 主人公の宝石と同じ青 |
| 火（fire）・燃えさし（ember） | 炎・薪の火 | 赤 → 橙 → 黄 → 白 |
| 葉（leaf）・苔（moss） | 薬草・草・石の苔 | 緑 |
| 肉（meat）・脂（fat） | 肉のアイコン | 赤・薄桃 |
| 軌跡（slash） | 剣の軌跡 | 白 → 水色 → 青 |

## 決めてほしいこと

1. **この絵柄で進めてよいか**（赤い瓦の屋根としっくい壁の村、石と青い光の仕掛け、ふちの線の色、光は左上から）
2. **家の大きさ**：`ART.md` の決まり（96×112、扉の高さ 64）で作りました。今の仮の絵（96×80）より縦に長く、屋根が上のマスにかぶります。この高さでよいか
3. **家の扉が大きい**：扉 64 以上の決まりのため、家の正面の多くを扉が占めます。この見た目でよいか、それとも家の絵を 128 くらいまで高くして屋根を大きく見せるか
4. **仕掛けが働いている色**：青（主人公の宝石と同じ）で統一してよいか。地方ごとに色を変える（例：砂漠は金、雪山は白）案もあります
5. **獣の肉のアイコン**：生肉（赤）で描きました。「焼くとおいしい」の生の肉としてこのままでよいか（焼き肉は別のアイコン `icon.food` で作る予定）
6. **剣の軌跡の色**：白〜青にしました。「灯火の剣」（火の剣）などで軌跡の色を変えたい場合は、色違いを追加で作るか
7. **宝箱を開けた後**：今は「空っぽで暗い中が見える」です。中に光る物（中身が残っている印）を描くかどうか
8. **地面の影**：絵には影を入れず、ゲーム側の影（`fx.shadow`）に任せる方針でよいか
9. **次の順番**：おすすめは「家具 → 仕掛け → アイコン・効果 → 自然の物・木」（村の中と謎解きの場所から先に揃う）
