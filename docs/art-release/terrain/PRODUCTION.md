# 地形の本番の絵 — 制作記録（ブランチ `art/terrain-release`）

承認ずみの方法（PR #52 の見本・作り方、PR #51 のスタイルガイド、四季は「ランプの置き換え＋手描きの足し物」、道のさかい目はまっすぐ、濃い水）で、`docs/art-kit/LIST.md` の地形の絵を全部作りました。
**ゲームにはまだつないでいません**（`main.js` などは変更なし。つなぐのは監督の作業。PR #50 が入ると `src/art-release/<まとまり>/` は自動で読み込まれます）。

- 絵：`src/art-release/terrain/<名前>.png`（**111 枚**）
- 作る道具：`tools/terrain_release/gen_release.py`（`python3 tools/terrain_release/gen_release.py`、Pillow が必要）
  - `release_ground.py`（地面・特別なマス）、`release_faces.py`（崖の側面）、`release_nature.py`（木・針葉樹・自然の物）、`ramps.py`（色）
  - 見本 21 枚は `gen_samples.py` の関数をそのまま使っているので、**承認された見本と 1 ドットも違いません**（比べて確認ずみ）
- 確認用の画像：この フォルダー
  - `sheet.png`：全部の絵を名前つきで 4 倍
  - `repeat/repeat_<名前>.png`：地面 1 枚ずつ 4×4 に並べたもの（2 倍）
  - `repeat/mixed_<季節><地面>.png`：地方ごとの種類違いを、ゲームと同じ選び方（`hash(x, y) % n`）で 8×8 に混ぜたもの
  - `repeat/stack_face.<素材>.png`：崖を `gameView.addFace` と同じ積み方（1/4・1/2・1・2・1.25 段）で積んだもの（土・岩・遺跡・壁・秋の土・冬の土）
  - `objects_on_grounds.png`：木と物を 5 つの地面（草・砂・雪・水・床）の上に置いたもの（3 倍）
  - `check.txt`：プログラムで数えた確認（下の「確認したこと」）
- テスト：`tests/unit/terrainRelease.test.js`

## 絵ごとの描き方

| 絵 | 描き方 |
|---|---|
| `tile.ruin` | 遺跡の石（ruin.stone）の大きな石板。段ごとに継ぎ目をずらす。上と左のふちが明るい。1 枚しか無いマスなので、目立つ印（割れ目・彫った線）は格子に見えたのでやめ、小さなひびとすり減りだけ |
| `tile.wood` | 長い板（wood）を 8 ドットの段に。板の端の継ぎ目は 1 枚の中で 1 段に 1 つ、段ごとに位置をずらす。継ぎ目は 1 番（`#4a2c16`）。木目の線と節を 1 つ（下の「`tile.wood` の直し」） |
| `tile.metal` | 鉄（iron）の 16 ドットの板 4 枚。継ぎ目の上と左が光る。2×2 のびょう、斜めの光の線（電気を通す床とわかるように金属らしく） |
| `tile.pit` | 穴。上の 5〜7 ドットが向こう側の土の壁（earth.face、上のふちが光る）、その下は真っ暗（cave.rock 0）に暗いほこりが少し |
| `tile.dark` | 部屋の外（何もない所）。cave.rock の 0 番 1 色 |
| `tile.vine` | 水や穴の上に出るつるの足場。葉（tree.leaf）のマットに幹の色（tree.bark）のつるを編んだ形。外側は透明で、輪郭つき（地面ではなく「置く物」なので） |
| `tile.ramp` | 32×64 の石段（wall.stone）。8 段。段の鼻が明るく、け上げが暗い。継ぎ目の位置は段ごとに違う。左右の側桁は左が明るく右が暗い |
| `face.ruin.*` | 遺跡の石を積んだ壁。`top` は光る笠石と、その下の影の線、その下の明るい帯。石の明るいふち（3 番）は `top` の 1 段目だけで、2 段目と `mid` からは 2 番（上のふちの 1 行だけ残す）。`-base` は下半分を 1 段暗く（石の継ぎ目の 0 番はそのまま残す）、いちばん下が 0 番。積むと上から暗くなる（行の平均の明るさ：`top` 33.8 → `mid` 32.7 → `mid-base` 29.1）。`mid.8` に小さな彫り線 |
| `face.wall.*` | 家の壁。`top` は壁の上の石（`tile.walltop` と同じ wall.stone）→ 梁（wood）→ しっくい（room.plaster）の明るい帯。`-base` は幅木（wood）、いちばん下が 0 番 |
| `face.stone.*` | 雪山の崖。灰紫の岩（mount.rock）。上に雪のふち（mount.snow）と垂れた雪。角ばった岩の面と縦のひびで、土の崖と見分ける。明るさは土の崖と同じく上から 3→2→1 |
| `desert.sand.0-2` | 赤い砂の風紋。1 に小石 2 つ、2 に半分埋まった岩（desert.stone） |
| `forest.grass.0-3` | 苔（forest.moss）のふくらみと短い草。1 に落ちた針葉、2 にシダ（forest.pine）、3 に小さなきのこ 2 本 |
| `mountains.snow.0-3` | 雪の吹きだまり（上が明るく、風下が青い影）。1 に雪をかぶった岩、2 に凍った水たまり（mount.ice）。3 は吹きだまりだけ（物は 4 マスに 2 つ。デザイン確認の指摘 2） |
| `lake.grass.0-3` | 岸の草（lake.grass）。島の草と同じ草の束の絵を別の並べ方で。1 に枯れ色の葦、2 に浜の小石、3 にクローバー |
| `forest.pine` | 32×60。針葉の段を 5 つ重ね、上の段が下の段に影を落とす。段の下のふちは枝先が垂れる形。左と上のふちに光る縁（3 番、ところどころ 4 番）。暗い森の苔の上でも 1 倍で形が見えるように（デザイン確認の指摘 3） |
| `mountains.pine` | 雪山の木。同じ作りで幅を 8 割（細い高山の木）、各段の上に厚い雪 |
| `obj.rock` | 丸い岩（pebble）。左上が明るく、面の折れ目と右下のひび、足元に草 |
| `obj.bramble` | いばら。くすんだ緑の葉（forest.swamp、3 番中心。森の苔より明るくして 1 倍で見つけやすく）のかたまりに、とげのあるつる（tree.bark）、外に飛び出たとげの枝、赤い実 2 つ |
| `obj.stump` | 切り株。上は年輪（wood）、横は樹皮（tree.bark）、根が左右に広がる |
| `obj.cactus` | サボテン（新しい色 cactus：青み寄りの緑）。腕 2 本、縦のすじ、とげ（2 ドット）、上に花のつぼみ、足元に砂 |

## 四季（承認ずみの方法）

形は夏の絵と同じ（同じ関数で描いて、色の置き換えは 5 段の番号どうし）。そのうえで必ず手描きの足し物を入れる。

| 季節 | 絵 | 置き換え | 手描きの足し物 |
|---|---|---|---|
| 春 | `spring.obj.tree` | なし（夏の木のまま） | ピンクの花（flower.pink）の小さなかたまり 18 個。明るい面は 3〜4 番、影の面は 1〜2 番 |
| 秋 | `autumn.tile.grass.*` `autumn.plains.grass.*` | 草 → 秋の草（autumn.grass、ガイド 3.7） | 落ち葉（火の色 fire の 1〜2 番、ガイド 3.7 と同じ色）を 2〜3 枚。平原の花の場所には落ち葉 |
| 〃 | `autumn.lake.grass.*` | 岸の草 → 枯れ色（lake.reed） | 落ち葉。葦のかたまりは秋の草の色にして、くすんだ岸の上で金色に見えるように |
| 〃 | `autumn.face.earth.top*` | 崖の上の草 → 秋の草 | ふちに落ち葉 3 枚 |
| 〃 | `autumn.obj.tree` | 葉 → 秋の葉（autumn.foliage、新規） | 足元に落ち葉 |
| 冬 | `winter.tile.grass.*` `winter.plains.grass.*` `winter.lake.grass.*` `winter.forest.grass.*` | 地面の草・苔 → 雪（mount.snow） | 雪の上では草の束の明暗が夏の約 3 倍になり「汚れた雪」に見えたので（デザイン確認の指摘 1）、草の束は**影（0〜1 番）を描かず、明るい形（3 番、2 ドット以上）だけ**を、夏と同じ場所に**1 つおき**に残す。雪から出ている草の葉（夏の草の色）は 1 枚に 1 か所。平原の花の場所には雪の盛り上がり。湖の葦は上の部分だけ雪から出る。森は 1 枚に暗い物 1 つまで（針葉 1 か所、シダと きのこは低木の先に描き替え） |
| 〃 | `winter.face.earth.top*` | 崖の上の草 → 雪 | ふちの丸い雪の盛り上がり、光る点、垂れた雪 3 か所 |
| 〃 | `winter.obj.tree` | なし | 葉のかたまりの上側に雪（3〜4 番、右側は 1〜2 番の青い影） |
| 〃 | `winter.forest.pine` | なし | `forest.pine` と同じ形で、各段の上に雪（2 行） |
