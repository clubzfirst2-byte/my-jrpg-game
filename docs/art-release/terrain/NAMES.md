# Terrain v1.1: new sprite keys (for wiring)

264 new PNGs in `src/art-release/terrain/` (the 111 of v1.0 are unchanged). Generated by `tools/terrain_release/gen_release.py` (`release_v11.py`); this file is written by it too.

- Anchor: **top-left** for every tile and face (like `tile.*` / `face.*`); **feet** (bottom centre) for the pines.
- Frames: `.0` / `.1` at the end of the water-edge keys = the 2 frames of `tile.water` (show the same frame as the water). Everything else has 1 frame.
- Mask (water edges): bit N = 1, E = 2, S = 4, W = 8 = the 4-neighbours that are WATER; 1-15. `inner.<ne|se|sw|nw>`: no 4-neighbour is water, only that diagonal one. A tile with mask 0 and 2+ diagonal water neighbours has no piece (use the plain ground; rare in the maps).
- Season keys follow the existing scheme `<season>.<key>` (gameView.seasonKey).
- Each water-edge piece's 2 frames differ by 12-30 px, like `tile.water` (guide 3.5).
- No water edge for path (`=`) or ruin floor (`u`) next to water (~150 tiles in the maps): they keep the straight edge (built stone and roads; by design).
