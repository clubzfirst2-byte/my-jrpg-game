# UI の絵 v2（W4：タイトル・ボタン・メニュー）

グラフィック 100 点計画（`gfx_plan.md`）の W4。ベースラインの「ゲーム画面全体 33 点」の原因（タイトルがグラデーションとシステムフォントだけ、灰色の丸ボタン、ウェブページのようなメニュー）を、ゲームのドット絵の作りで描き直しました。

- 絵：`src/art-release-v2/ui/`（98 枚＋`manifest.json`）。**まだゲームにはつないでいません**（つなぐのは UI エンジニア）。既存の絵・`src/art-release/*` は変えていません
- 作り方：`python3 tools/ui_v2/gen_ui.py`（毎回同じ絵。`NAMES.md` と `manifest.json` も作る）→ `python3 tools/ui_v2/review.py`（`review_sheet.png`）→ `python3 tools/ui_v2/mockups.py <baseline/15pro> docs/art-release-v2/ui/mockups`
- 大きさ・9 スライスの値：**`NAMES.md`**（エンジニア向け。全ファイルの絵の大きさ・CSS の大きさ・内側の幅）と `manifest.json`（同じ内容を JSON で）
- テスト：`tests/unit/uiV2Art.test.js`（ファイルと manifest が一致、大きさ、密度、ボタン 44 px 以上、アイコンがボタンに入る、9 スライスの値）

## 決めたこと

### 1 ドットの大きさ（いちばん大事）

| 対象 | 絵 1 ドット | iPhone 15 Pro（DPR 3） | SE（DPR 2） |
|---|---|---|---|
| HUD・ボタン・メニュー・ハート | **1 CSS px** | 3 画素 | 2 画素 |
| タイトル（ロゴ・背景） | **2 CSS px** | 6 画素 | 4 画素 |

- どちらも端末の画素の**整数倍**なので、ドットが 2 px と 3 px に割れない（ゲーム画面の 2.5 倍問題を UI には持ち込まない）
- 1 CSS px は、メニューの持ち物アイコン（今も 1 絵ドット＝3 画素）と同じ密度。ゲーム画面の地面（2.5 画素）にもいちばん近い
- 必ず `image-rendering: pixelated`。CSS で `width`/`height` を「絵の大きさ × cssScale」ちょうどにする（中途半端な大きさにしない）

### 色と光

- ガイドのランプを使う：**宝石の青（gem）と金（gold）＝星環**、鋼（steel）、遺跡の青緑（ruin_glow）、家具の木（chestwood）、赤い実（berry＝ハート）、澱の紫（miasma＝ボスのバー）
- UI 用に足したランプ（UI はワールドの絵ではないので、`tools/ui_v2/common.py` に置いた）：`navy`（今の `--panel` の紺を 5 段に）、`sky`・`dusk`・`sea`（タイトルの空と海）
- 光は左上から（ワールドと同じ）：枠の上と左が明るく、下と右が暗い。ボタンの縁も左上が明るい（押した時は逆）
- 半透明：HUD の丸ボタンの「ガラス」（アルファ 150）と、パネルの中（236＝今の 0.94 と同じ）だけ。縁・アイコン・文字の下地は不透明

### 文字

- 日本語の文字は**今の読みやすいウェブフォントのまま**（HTML）。絵にしたのはロゴだけ
- 12 px 以上・ボタン 44 px 以上は変えない。9 スライスの枠は内側の幅（8〜11 px）を引いても、44 px のボタンに 12〜16 px の文字が入る

## 作ったもの

### タイトル

- `title.logo`（260×64 → 520×128 CSS）：「星環のレガリア」。字は金のランプ（上が明るい）、紺の輪郭と青の外線、下に影。「の」を**星環の紋章**（宝石の青の輪に 8 つの星、上に金の四つ星）の中に置いた。**字はすべてオリジナルの手描きのドット絵**：1 字ずつ 24×24 の升目に線（横・縦・折れ線）で書いたもの（`tools/ui_v2/title.py` の `GLYPHS`）を 1.25 倍・太さ 2 px にした。フォントは使っていない・なぞっていない
- 背景（各 480×200 → 960×400 CSS。15 Pro の 852×393・SE の 667×375 を覆い、左右に 50 px 以上の余り＝視差で動かせる）
  - `title.bg.sky`（視差 0）：夕暮れの空（段の色の帯、縁はまっすぐでない）、星、**空にかかる星の輪**（タイトルの由来）、細い雲
  - `title.bg.far`（0.15）：水平線の海、夕日のきらめき、遠くの島
  - `title.bg.mid`（0.4）：右の岬（草・崖）、**光る星環の輪**、灯台塔、木
  - `title.bg.near`（1.0）：手前の草と花、左上に枝
  - `title.bg`：4 枚を重ねた 1 枚（視差を使わない時用）
- タイトルのボタンは `btn.text.*`（はじめから＝`selected`、つづきから＝`idle`、無い時＝`disabled`）

### HUD のボタン

- 丸ボタン `btn.ring.<色>.<直径>.<idle|pressed>`：紺の輪郭、金属の縁（3 px、左上が明るい）、内側の暗い線、ガラスの中身（左上に光の三日月）。押すと縁の光が逆になり、中が色づく
  - 色：攻撃＝**金**（主のボタン）、能力＝**青緑**（今の水色の能力ボタンと同じ考え）、ほか＝**鋼**
  - 直径は**今の CSS の 3 つの大きさ（小 0.85・中 1・大 1.15）ちょうど**に作った（拡大しない）。一覧は `NAMES.md` の最後の表
- アイコン `icon.ui.<名前>.<20|26|34>`：攻撃（剣）・ジャンプ（上矢印と地面）・回避（回る矢印）・弓（弓と矢）・ガード（盾）・ダッシュ（二重の山形）・能力（星の輪）・⇄（入れかえ）・一時停止（2 本線）・持ち物（袋）・閉じる（×）。白っぽい骨色（攻撃は金、能力は青緑）、左上が明るく、紺の輪郭。同じ形から各大きさで描き直しているので、どの大きさでもにじまない
- 一時停止・持ち物は `btn.text.*`（角の丸い板）＋アイコン 20

### パネル（9 スライス）

| 名前 | 使う所 | 見た目 | 内側（絵 px） |
|---|---|---|---|
| `panel.menu` | 持ち物・設定・一時停止 | 紺、鋼の青の縁、四隅に金の鋲 | 10 |
| `panel.dialogue` | 会話 | 紺、金の縁、四隅に青い四つ星 | 10 |
| `panel.nameplate` | 会話の話し手の名札 | 金の縁 | 5 |
| `panel.shop` | 店 | 赤茶の木の縁（カウンター）、四隅に金の金具 | 11 |
| `panel.ending` | エンディング | 金の二重の縁と青い線、四隅に星の輪のメダル | 16 |
| `panel.toast` | トースト | 細い青の縁 | 5 |
| `panel.crest` | 一時停止・設定の上の縁に載せる紋章（9 スライスでない） | 星の輪と金の星 | — |

- 縁の模様は**長さ方向に一様**（飾りは角だけ）なので、`border-image-repeat: stretch` でドットがゆがまない
- タブ `tab.idle / active / pressed`、行 `row.idle / selected / pressed`、文字ボタン `btn.text.idle / pressed / selected / disabled`
- その他：`cue.more.0/1`（「下にまだある」「次へ」の金の山形、2 コマで 1 px 上下）、`heart.0〜4`（22×20＝今の HUD と同じ大きさ。0＝空、1〜3＝左から 1/4 ずつ、4＝満タン。今の HUD と同じく左から埋まる）、`bossbar.frame`（9 スライス、両端に紫の鋲）、`bossbar.fill.1/2`（4×4 を横にくり返す。1＝紫、2＝第 2 形態の赤）

## 決めてほしいこと・残り

1. ~~ボタンの文字ラベル~~ → 決定：丸ボタンはアイコンだけ＋`aria-label`。最初の数回だけ文字ラベルを出すのと、設定の切り替えはエンジニアが作る（絵の変更なし）
2. **ボタンが画面の約 1/4 を覆う問題**：44 px の決まりと今の配置を変えないので、面積は同じ。重さは減らした（灰色の不透明に近い円 → 縁だけはっきりした薄いガラス）。もっと減らすなら配置（間隔・半円の並び）を変える作業になる
3. **つなぐ作業（UI エンジニア）**：`?ui=v1` で今の UI に戻せる切り替え（計画の決まり）、`#ui.text-large` の時の大きさ、safe area（ノッチ）の内側でのパネルの位置、`prefers-reduced-motion` で `cue.more` の 2 コマを止める
4. **タイトルの背景**：岬の崖は単純な面。W1（地面）・W5（光）の絵が決まったら、その色と描き方に合わせて描き直したい
5. ~~ロゴの字のフォント~~ → 字はすべて手描きにした（フォントのライセンスの問題なし）
