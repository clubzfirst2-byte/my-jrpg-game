# 品質方針：最初から製品版品質で作る（2026-11-06 決定）

> この文書は開発のいちばん上の決まりです。`docs/DESIGN.md` の「開発上の重要ルール」より優先します。

## 1. 原則
- 仮素材・仮デザイン・仮実装を前提に作らない。**新しく作るものは、最初から正式採用を前提とした完成品質で作る**
- 対象：主人公・NPC・敵・ボス、キャラクターのアニメーション、背景・地形・建物・自然物、武器・防具・アイテム、エフェクト、UI・アイコン、BGM・効果音
- 禁止：単純な色違い、使い回し感の強いデザイン、低解像度の絵を拡大しただけの見せかけの高解像度化
- 開発途中だからという理由で品質を妥協しない

## 2. ゲームシステム
- 探索、戦闘、敵 AI、NPC 会話、クエスト、装備・成長、料理・クラフト、セーブ・ロード、マップ・イベント、スマートフォン操作は、最初から本番実装を目指す
- 動くだけの簡易実装ではなく、完成版でそのまま使い続けられる設計にする

## 3. 品質確認（作ったあと必ず行う）
| 対象 | 確認のしかた |
|---|---|
| キャラクター | ゲーム内の表示サイズで見分けられるか |
| アニメーション | 連続再生で破綻しないか |
| 背景 | 実際のゲーム画面に入れて確認 |
| UI | iPhone の画面で操作しやすいか |
| システム | 実際にゲームを遊んで確認 |

- 基準に届かないものは正式採用しない

## 4. 既存素材の扱い
- 主人公 v2（`src/art-proto/hero/`）、第 1 回・第 2 回の NPC、第 1 回の敵、第 3 回の敵（作業途中）は**既存資産として保護**する（消さない・上書きしない）
- ただし最終品質に達しているかは別に評価し、自動的に完成品とはしない
- 改善が必要なら、今のファイルは残したまま新しい完成版を作り、比較・承認を経て差し替える

## 5. 進め方
- 品質を保ちながら、関連する素材・機能はまとめて作る
- 小さな仮素材を何度も作り直す作業をなくし、最初から完成版に使える成果物を増やす

## 6. 完成の条件
- 「仮素材がある」「動作確認だけできた」「後から作り直す予定」は完成としない
- 最終的にプレイヤーへ出せる品質に達していることを完成の条件とする
