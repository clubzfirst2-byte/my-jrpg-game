- スプライトは既存プロジェクトのタイルサイズ、キャラクター表示寸法、アニメーション形式を調査してから合わせる。
- フレーム数・配置・原寸サイズを明記する。
- 既存CC0素材を変更・削除・上書きしない。
- 未完成の仮素材を正式素材として扱わない。
- 主人公本人の台詞は表示せず、表情や仕草で反応を表現する。NPC、姫、仲間は通常どおり会話してよい。
