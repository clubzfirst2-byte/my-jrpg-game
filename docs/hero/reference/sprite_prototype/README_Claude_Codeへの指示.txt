重要：この画像はゲームへの直接投入用の完成スプライトシートではありません。
画像生成によるコンセプトシートであり、見出し・背景・余白を含みます。各コマが厳密な32×56ピクセルで区切られた透過PNGではありません。画像全体をゲームのテクスチャとして登録しないでください。

Claude Codeへの作業指示
1. この画像を主人公の動作・配色・衣装の参考資料として扱ってください。
2. 既存のゲーム側のスプライト読込仕様、座標系、向きの順序、アニメーション定義を先に確認してください。
3. 主人公の正式デザインは、別途承認済みの主人公デザイン資料（顔・髪・緑のマント・青い星環ペンダント）を優先してください。このシート内で顔が異なる場合は、承認済み顔デザインに合わせてください。
4. この参考シートをもとに、ゲーム用の個別フレームを新規に清書してください。各フレームは32×56ピクセル、背景透過、同一の足元基準・同一キャンバス寸法にしてください。
5. 必要な仮アニメーションは、歩行3コマ×4方向、待機1コマ×4方向、水泳2コマ×4方向の計24コマです。
6. 方向の並び順・フレームの並べ方は、既存実装と一致させてください。既存仕様を確認せずに推測しないでください。
7. 完成した仮素材はゲームに組み込み、ゲーム画面で表示・アニメーション・当たり判定を確認できるようにしてください。
8. 当たり判定は画像サイズと分離し、足元を基準に維持してください。
9. 既存CC0素材やP11の機能を変更・削除・上書きしないでください。
10. 仮素材を正式採用にせず、スクリーンショットと素材一覧を提示してユーザー承認を待ってください。
