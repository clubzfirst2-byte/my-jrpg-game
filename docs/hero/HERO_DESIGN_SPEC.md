## 1. 人物像

- 旅を続ける少年。**少年らしさ・意志の強さ・神秘性**を併せ持つ
- 豪華な騎士ではなく、**使い込まれた装備の旅人**

## 2. 部位ごとの基準

| 部位 | 基準 | 変えてよいか |
|---|---|---|
| 顔 | 少年の顔立ち。意志の強さと神秘性。以後の素材で同じ顔に見えること | ✕（表情は §5 の範囲で変える） |
| 髪 | **茶色**。少し無造作で、**左右非対称の前髪** | 色・前髪の形は ✕。風でなびく等の動きは ○ |
| 目 | **切れ長**、**青い瞳** | ✕ |
| 衣装 | **緑を基調とした旅人の服**。使い込まれた質感（擦れ・継ぎ当て程度） | 基調色の緑は ✕。装備差分（§7）で上着・小物は ○ |
| マント | **緑のマント**。シルエットの主役 | 形・丈の細部は ○、緑とマントがあることは ✕ |
| ペンダント | **青く輝く「星環のペンダント」**。胸元。シルエットでも分かる大きさ・光 | ✕（どの装備でも常に見える） |
| 装備 | 旅人らしい実用品（革のベルト・ポーチ・ブーツ）。**過度に豪華な鎧にしない** | ○（§7） |

**シルエットの決まり**：黒一色にしても「緑のマント」と「胸の光るペンダント」で主人公と分かること（ペンダントは光の点として残す）。

## 3. 代表色

ドット絵の基準色です（明・中・暗の 3 段）。周りの色に合わせた微調整は可、色相は変えません。

| 用途 | 明 | 中（基準） | 暗 |
|---|---|---|---|
| 衣装・マント（緑） | `#7fbf5a` | `#4f8a3a` | `#2f5426` |
| 髪（茶） | `#a0683e` | `#7a4a2a` | `#4e2e1a` |
| 瞳（青） | `#7fd0ff` | `#3a8fd8` | `#1f4f8a` |
| ペンダント（光る青） | `#d8f4ff` | `#5cc8ff` | `#2a78c8` |
| 革・装備（茶系） | `#b08860` | `#7a5a3a` | `#4a3424` |
| 肌 | `#f6d2b0` | `#f2c49b` | `#c8946c` |
| 輪郭線 | — | `#1a1c2c`（ゲーム共通の輪郭色） | — |

注意：ゲームの地面（草）も緑です。**マントの緑は草より少し黄み寄り・明るめ**にし、輪郭線で必ず縁取って、草の上で埋もれないようにします（§6 の確認項目）。

## 4. 向きごとの見え方（三面図の基準）

ゲームは見下ろし型で、**下・上・左・右**の 4 方向を使います（左は右の左右反転で作ってよい。ただし前髪の左右非対称とペンダントの位置は反転後も破綻しないこと）。

| 向き | 見えるもの |
|---|---|
| 正面（下向き） | 顔（切れ長の青い目・非対称の前髪）、胸のペンダント（光）、緑の服、マントの両端 |
| 背面（上向き） | 茶色の後頭部、**緑のマントが背中の大部分**、ペンダントの紐（光は見えなくてよい） |
| 側面（左右） | 横顔（目は 1 つ）、前髪の流れ、マントが後ろへ流れる形、ペンダントの光が胸の前に少し出る |

## 5. 感情表現と台詞の方針

- **主人公本人の台詞は表示しない。** 会話の吹き出し・文字欄に主人公の言葉を出さない
- これは無感情・無反応という意味ではない。反応は **表情・視線・うなずき・身振り・行動・演出** で表す
- NPC、姫、仲間は通常どおり話してよい
- 会話の選択肢は **短い行動・意思の言葉**（例：「引き受ける」「また今度」）にとどめ、主人公の長い発話文にしない。選んだ結果は相手の反応や行動で伝える
- 現状の確認（P11.5 時点）：主人公が話す会話はなく、選択肢は最長 6 文字（`data/dialogue.json`）。方針に沿っている

表情の種類（P12 で作るもの）：通常・笑顔・驚き・悲しみ・決意・痛み。
ゲーム画面の小さな絵（16〜24 ドット）では目と口の数ドット＋身振りで表し、細かい表情は顔の拡大絵（ポートレート）で表す。

## 6. 頭身・輪郭・視認性

| 項目 | 基準 |
|---|---|
| ゲーム内の大きさ | 今の仮素材は 16×16（頭 9・体 4・脚 3 ドット、約 2 頭身）。本番は **幅 16、高さ 16〜24** を目安（2〜2.5 頭身）。足元（下の中央）が立ち位置 |
| 当たり判定 | 絵と別。幅 10・高さ 6（`player.js`）。**絵を大きくしても変えない** |
| 輪郭 | 1 ドットの輪郭線（`#1a1c2c`）。草・砂・雪・水の上でも主人公が浮き出ること |
| 確認する背景 | 草原・森（濃い緑）・砂漠・雪山・水の上・夜（暗くなる） |
| 縮小・拡大 | 1 ドット＝ゲーム内 1 ドットで描く。**小さい絵を拡大しただけのものは完成品にしない** |

## 7. 変えてよい所・変えない所

- **変えない**：顔立ち、茶色の非対称な前髪、切れ長の青い目、緑の基調とマント、星環のペンダント（常に見える）
- **変えてよい**：装備差分（上着・肩当て・小物・武器・盾）、マントの破れや汚れ、季節の防寒具（ただし緑とペンダントは見えるまま）、表情・ポーズ

## 8. 画風と制作のルール

- 完全オリジナルの高品質ピクセルアート。2D 見下ろしのゲーム画面になじむこと
- 既存作品のキャラクター・衣装・固有の意匠・画像をまねしない／使わない
- 透過 PNG。背景・文字・説明ラベルを絵に入れない
- スプライトシートを渡す場合は、コマの並び・1 コマの大きさ・余白を必ず書く（ゲームに入れるときは 1 コマ 1 ファイルに分ける。`docs/ART.md`）
- 既存の素材は変更・削除・上書きしない。新しい素材は追加する
- 未完成の絵は完成素材として組み込まない（仮のものは名前か README に「仮」と書く）

## 9. 参照画像と素材の置き場所

| 種類 | 置き場所 | ファイル名 |
|---|---|---|
| 承認済みデザイン画（三面図・顔） | `docs/hero/reference/` | `hero_approved_front.png` `hero_approved_back.png` `hero_approved_side.png` `hero_approved_face.png`（ゲームには入らない） |
| ゲーム内の主人公の絵 | `src/art/characters/hero/sprites/` | 絵の名前そのまま（例：`player.walk.down.0.png`。§10） |
| 装備・滑空などの付属の絵 | `src/art/characters/hero/equipment/` | 同上（例：`fx.glider.png`） |
| 顔の拡大絵（ポートレート） | `src/art/characters/hero/portraits/` | `hero.portrait.<表情>.png`（例：`hero.portrait.smile.png`）※表示する画面は未実装 |

`src/art/` の PNG はゲームに組み込まれます（名前が合えば仮の絵と入れ替わる）。参照画像・作業用ファイルは `src/art/` に置かないこと。

## 10. 命名規則

`<もの>.<動作>.<向き>.<コマ番号>.png`（向き：`down` `up` `left` `right`、コマは 0 から）

- 今ある名前（そのまま差し替えられる）：`player.walk.<向き>.0〜2`、`player.swim.<向き>.0〜1`
- P12 で増やす名前は `docs/hero/P12_ASSET_LIST.md` を参照（`player.<動作>.<向き>.<コマ>` の形で統一）
